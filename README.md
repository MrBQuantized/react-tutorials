# React App

A React application built with **Vite** and **TypeScript**. This project is part of the [Frontend Learning Repository](https://github.com/MrBQuantized/frontend/blob/main/README.md) but is managed as a standalone app.

## 📁 Project Structure

```
.
├── public/               # Static assets served as-is
├── src/                  # Application source code
├── notes/                # Personal notes & documentation
├── index.html            # HTML entry point
├── package.json          # Dependencies & scripts
├── vite.config.ts        # Vite configuration
├── eslint.config.js      # ESLint configuration
├── tsconfig.json         # Root TypeScript config
├── tsconfig.app.json     # TypeScript config for the app
├── tsconfig.node.json    # TypeScript config for Node tooling
├── .gitignore
└── README.md
```

## 🛠️ Tech Stack

- **React** — component-based UI library
- **TypeScript** — typed JavaScript for safer code
- **Vite** — fast build tool & dev server
- **ESLint** — code quality & consistency

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm (comes with Node.js)

### Installation

```bash
npm install
```

### Development

Start the Vite dev server with hot module replacement:

```bash
npm run dev
```

The app will be available at the URL printed in your terminal (typically `http://localhost:5173`).

### Build

Create a production build:

```bash
npm run build
```

Output is generated in the `dist/` folder.

### Preview

Preview the production build locally:

```bash
npm run preview
```

### Lint

Run ESLint across the project:

```bash
npm run lint
```
